关于本应用

  • 数据来源：GitHub Trending 官方页面，服务器每日 08:00 自动抓取并按日期存档；启动时若当天缺失会自动补抓。
  • 飙升：今日新增 Star 最快的项目（官方日榜），卡片上标注 ⚡日增速（今日新增 ÷ 原有存量）、「周榜 #N / 月榜 #N」表示同时也在该榜，「首次收录」表示此前从未出现在任何榜单。
  • 周榜：最近 7 天新增 Star 前 20；月榜：本自然月至今新增 Star 前 20。
  • 月榜支持回看历史月份：进行中的月份标「至今」，已结束月份使用该月最后一次快照作为最终榜单。
  • 卡片上的 ▲▼ 表示与上一期快照对比的排名变化，NEW 为新上榜。
  • 断网时自动使用最近一次的本地缓存数据。部署到 GitHub Pages 后自动进入云端模式：数据由 GitHub Actions 每日抓取发布，手机无需电脑开机。

添加到手机主屏幕

  • Android（Chrome）：右上角菜单 → 「添加到主屏幕」/「安装应用」。
  • iPhone（Safari）：底部中间「分享」按钮 → 「添加到主屏幕」。
